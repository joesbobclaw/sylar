# Contributing

Sylar accepts capability specifications, evidence corrections, threat models, experiments, and implementation spikes.

## Evidence standard

- Use current first-party sources for competitor behavior.
- Check the current OpenClaw version and official documentation.
- Label a partial or productized difference as such.
- Do not treat connector counts or marketing adjectives as capability evidence.

## Specification standard

Every proposal must include:

- observable outcome
- nearest OpenClaw equivalent
- non-goals
- trust boundary
- MVP
- adversarial and recovery tests
- falsifiable acquisition test

Use [the template](docs/spec-template.md).

## Safety

Do not include credentials, private transcripts, personal data, or proprietary implementation material. Demonstrations and fixtures must be synthetic or explicitly approved for publication.
